ADC — AI Desktop Controller

Quick Start Guide:

1. Open desktop-agent\.env
2. Configure your Groq API key in GROQ_API_KEY
3. Open PowerShell in desktop-agent directory
4. Run: npm install
5. Run: npm test
6. Run: npm start
7. Open in browser: http://localhost:3000

Note: Do not use VS Code Live Server. Always use http://localhost:3000 served by the Node.js backend.
